# Reservoir Data Analytics 

Welcome to my data analytics portfolio. I am a first-year Petroleum Engineering student at Universiti Teknologi PETRONAS (UTP). 

## Project Goal
This repository contains Python scripts I am building to analyze reservoir engineering data, specifically focusing on:
1. Calculating Porosity from Well Logs.
2. Estimating Permeability using the Timur Equation.
3. Analyzing Production Decline Curves (DCA).

## Tools Used
- Python (Pandas, Matplotlib, Scipy)
- Git & GitHub

## Repository Files
- `porosity_calculator.py`: Calculates porosity from density log readings.
- `permeability_estimator.py`: Estimates permeability using the Timur equation.
- `decline_curve.py`: Generates a production decline curve using Matplotlib.
